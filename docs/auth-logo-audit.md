# Auditoria visual da logo da autenticação

- `public/icons/APEX_LOGO.png`: marca clara/branca, adequada para fundos escuros.
- `public/icons/APEX_LOGO_LIGHT.png`: marca preta/escura, adequada para o fundo branco atual da autenticação.
- A tela de autenticação deve usar `APEX_LOGO_LIGHT.png` nas versões desktop e mobile/tablet para obter o contraste solicitado.
- Os ícones do formulário (e-mail, senha e visibilidade da senha) devem usar preto ou quase preto, preservando a lógica de login.

Esta anotação é apenas um registro da auditoria e não altera o funcionamento do sistema.
